# NovaCart — Full-Stack Deployment & Project Architecture

A responsive e-commerce product catalog built with React + Vite.

## Features
- Modular React single-page application
- Client-side navigation with section anchors
- Product search and category filtering
- Shopping cart counter and total
- Light/dark theme toggle
- Responsive mobile/tablet/desktop layout
- Optimized, dependency-light frontend
- Ready for Vercel, Netlify, or Render static deployment

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy
Upload this project to GitHub and import it into Vercel/Netlify, or deploy the built `dist` folder to a static hosting service.

For the Thiranex submission, submit the public deployment URL after hosting the project.
